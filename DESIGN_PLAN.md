# A.D.ENTERPRISES Website - Design Plan

## Design Philosophy
The website will showcase A.D.ENTERPRISES as a professional, innovative, and reliable electrical panel manufacturing company. The design will balance technical credibility with modern aesthetics, using a professional color palette and clean typography.

## Color Palette
- **Primary Blue**: #0052CC (professional, trustworthy)
- **Accent Orange**: #FF8C00 (energy, innovation)
- **Dark Gray**: #1F2937 (professional background)
- **Light Gray**: #F3F4F6 (section backgrounds)
- **White**: #FFFFFF (text on dark backgrounds)
- **Text Dark**: #111827 (main text)

## Typography
- **Headings**: Inter or Poppins (modern, clean)
- **Body**: Inter (readable, professional)
- **Font Sizes**: 
  - H1: 48px (hero titles)
  - H2: 36px (section titles)
  - H3: 24px (subsections)
  - Body: 16px (regular text)

## Website Structure

### 1. Header/Navigation
- Fixed or sticky navigation bar
- Company logo on the left
- Menu items: Home, About, Products, Infrastructure, Certifications, Contact
- CTA button: "Request Quote" or "Get in Touch"
- Mobile hamburger menu

### 2. Hero Section
- Full-width background image (electrical panel manufacturing)
- Bold headline: "Premium LV Switchboards & LT Bus Duct Manufacturer"
- Subheading with company tagline
- Two CTA buttons: "Explore Products" and "Contact Us"
- Overlay with semi-transparent dark background for text readability

### 3. About Section
- Company introduction
- Key statistics (since 2006, ISO certified, etc.)
- Brief company mission statement
- Two-column layout: text + image

### 4. Products Section
- Grid layout (2-3 columns) showcasing product types:
  - Power Control Centre (PCC)
  - Motor Control Centre (MCC)
  - APFC Panel
  - AMF Panel
  - Synchronizing Panel
  - Feeder Pillar
  - LT Bus Duct
- Each product card with:
  - Product image/icon
  - Product name
  - Brief description
  - "Learn More" link

### 5. Infrastructure & Testing Section
- Showcase manufacturing capabilities
- List of machinery and equipment
- Testing certifications (CPRI, ERDA)
- Test results (70 KA, 100 KA withstand tests)
- Professional layout with icons and statistics

### 6. Certifications Section
- ISO 9001:2015 certification badge
- CPRI testing certification
- ERDA testing certification
- IP 65 protection rating
- Temperature rise test certification

### 7. Contact Section

## Design Elements
- **Icons**: Use Lucide React icons for visual hierarchy
- **Cards**: Subtle shadows and hover effects for interactivity
- **Spacing**: Consistent padding and margins (8px grid system)
- **Animations**: Smooth transitions and fade-in effects on scroll
- **Images**: High-quality product images and manufacturing facility photos
- **Responsive Design**: Mobile-first approach with breakpoints at 640px, 1024px, 1280px

## Interactive Elements
- Hover effects on product cards
- Smooth scroll navigation
- Form validation on contact form
- CTA buttons with hover states
- Mobile-responsive hamburger menu

## Accessibility
- Semantic HTML structure
- ARIA labels for interactive elements
- Sufficient color contrast ratios
- Keyboard navigation support
- Alt text for all images

## Performance Optimization
- Image lazy loading
- Optimized CSS and JavaScript
- Fast page load times
- SEO-friendly meta tags
- Mobile optimization
